How Jenkins Work
Developer pushes code → GitHub/GitLab
Jenkins detects change (via webhook)
Jenkins Pipeline runs:
Pulls latest code
Installs dependencies
Runs tests (npm test)
Builds (npm run build)
Deploys (to Netlify, AWS, etc.)
Sends notification (Slack/Email) with build status
