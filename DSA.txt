Time Complexity and Space Complexity ***
Time Complexity tells you how much time your algorithm takes relative to the input size n.
It does not give you the actual time (in seconds).
It gives you how the running time grows as the input grows.

Notation	Meaning				Explanation															Example
O(1)		Constant Time		Fastest! Takes the same time no matter the input size.				Accessing an array element
O(log n)	Logarithmic Time	Cuts problem size in half at each step. Super efficient!			Binary Search 
O(n)		Linear Time 		Grows directly with input size.										Looping through an array
O(n log n)	Linearithmic Time	Common in efficient sorting (Merge Sort, Quick Sort).				Merge Sort, Quick Sort
O(n^2)		Quadratic Time		Bad! Nested loops. Avoid if possible.								Bubble Sort, Nested Loops
O(2^n)		Exponential Time	Horrible! Used in brute-force recursion (Fibonacci, subsets).		Recursive Fibonacci
O(n!)		Factorial Time		Worst! Used in permutations & backtracking problems.				Permutations, Backtracking


Space Complexity tells you how much extra memory your algorithm needs to work, relative to input size.
It includes:
Temporary variables
Function call stack
Data structures used internally

Loops → O(n)
Nested Loops → O(n^2)
Divide & Conquer (Binary Search, Merge Sort) → O(log n) or O(n log n)

Sorting Algorithms ****

1.Selection Sort
Find the smallest element in the array.
Swap it with the first element.
Find the next smallest element and swap it with the second element.
Repeat until the array is sorted.

function selectionSort(arr) {
    let n = arr.length;
    for (let i = 0; i < n - 1; i++) {
        let minIndex = i; // Assume the first element is the smallest
        for (let j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) { // Find smaller element
                minIndex = j;
            }
        }
        // Swap smallest element with current position
        [arr[i], arr[minIndex]] = [arr[minIndex], arr[i]];
    }
    return arr;
}

// Example Usage
console.log(selectionSort([64, 25, 12, 22, 11])); 
// Output: [11, 12, 22, 25, 64]

Case							Complexity
Best Case (Already Sorted)		O(n²)
Worst Case (Reverse Sorted)		O(n²)
Average Case (Random Order)		O(n²)

Why is it O(n²)?
It has two nested loops:
Outer loop runs n times → O(n)
Inner loop runs n, n-1, ..., 2 times → O(n)
Total: O(n × n) = O(n²)


2.Bubble Sort
Bubble Sort is one of the simplest sorting algorithms.
It repeatedly swaps adjacent elements if they are in the wrong order, "bubbling" the largest element to the end.

Compare adjacent elements in the array.
If the left element > right element, swap them.
Repeat for all elements, pushing the largest element to the right.
Reduce the range and repeat until sorted.

function bubbleSort(arr) {
    let n = arr.length;
    let swapped; // Flag to optimize

    for (let i = 0; i < n - 1; i++) {
        swapped = false;
        for (let j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                // Swap elements
                [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
                swapped = true;
            }
        }
        // If no swaps, array is already sorted
        if (!swapped) break;
    }
    return arr;
}

// Example Usage
console.log(bubbleSort([64, 25, 12, 22, 11]));
// Output: [11, 12, 22, 25, 64]

Case							Complexity
Best Case (Already Sorted)		O(n) ✅ (With optimization)
Worst Case (Reverse Sorted)		O(n²) ❌
Average Case (Random Order)		O(n²) ❌

Why is it O(n²)?
Outer loop runs n times → O(n)
Inner loop runs n-1, n-2, ..., 1 times → O(n)
Total: O(n × n) = O(n²)


3.Insertion Sort
Start with the second element (since a single element is already "sorted").
Compare it with elements before it and insert it in the correct position.
Repeat for all elements until the array is sorted.

function insertionSort(arr) {
let n = arr.length;
 for (let i = 1; i < n; i++) {
        let j = i;
		 while (j > 0 && arr[j-1] > arr[j]) {
			let temp= arr[j-1]
			arr[j-1]= arr[j]
            arr[j] = temp;
            j--;
        }
	}
}

Case							Complexity
Best Case (Already Sorted)		O(n) ✅
Worst Case (Reverse Sorted)		O(n²) ❌
Average Case (Random Order)		O(n²) ❌

Why is it O(n²)?
Outer loop runs n-1 times → O(n)
Inner loop shifts elements → O(n) in worst case
Total: O(n × n) = O(n²)

Best Case O(n): If the array is already sorted, we only make n comparisons.


4.Merge Sort
Merge Sort is a divide and conquer sorting algorithm. It recursively splits the array into smaller subarrays, sorts them, and then merges them back together.

Divide: Split the array into two halves until each subarray has one element.
Conquer: Recursively sort each half.
Merge: Combine the two sorted halves into one sorted array.

function mergeSort(arr,low, high) {
	if(low === high) return
    let mid = Math.floor((low+high)/ 2);
    mergeSort(arr,low,mid); // Sort left half
    mergeSort(arr,mid+1,high); // Sort right half
    merge(arr,low,mid,high); // Merge sorted halves
}

function merge(arr,low,mid,high) {
    let result = []
	let left = low
	let right = mid+1

    while (left <= mid && right <= high) {
        if (arr[left] < arr[right]) {
            result.push(arr[left]);
            left++;
        } else {
            result.push(arr[right]);
            right++;
        }
    }
	while (left <= mid){
	result.push(arr[left]);
	left++;
	}
	while(right <= high){
	result.push(arr[right]);
	right++;
	}
	for(let i=low;i<=high;i++){
		arr[i]=result[i-low]
	}
}


let array=[64, 25, 12, 22, 11]
mergeSort(array,0,array.length-1)
console.log("array",array)
// Output: [11, 12, 22, 25, 64]

Case			Complexity
Best Case		O(n log n)
Worst Case		O(n log n)
Average Case	O(n log n)

Why O(n log n)?
Splitting: The array is divided log n times.
Merging: Merging takes O(n) time for each level.
Total: O(n log n).


5.Quick Sort
Quick Sort is a divide and conquer sorting algorithm that selects a pivot, partitions the array into two halves, and sorts them recursively.

Pick a Pivot (usually the last, first, or random element).
Partition the Array:
Move all elements smaller than pivot to the left.
Move all elements greater than pivot to the right.
Recursively Quick Sort both halves.

function quickSort(arr, low, high) {
  if (low < high) {
    let pivotIndex = partition(arr, low, high);
    quickSort(arr, low, pivotIndex - 1);
    quickSort(arr, pivotIndex + 1, high);
  }
}

function partition(arr, low, high) {
  let pivot = arr[low];
  let i = low;
  let j = high;
  while (i < j) {
    while (arr[i] <= pivot && i < high) {
      i++;
    }
    while (arr[j] > pivot && j > low) {
      j--;
    }
    if (i < j) {
      [arr[i], arr[j]] = [arr[j], arr[i]];
    }
  }
  [arr[low], arr[j]] = [arr[j], arr[low]];

  return j;
}

let array = [64, 25, 12, 22, 11];
quickSort(array, 0, array.length - 1);
console.log("array", array);


Case								Complexity
Best Case							O(n log n)
Worst Case (Unbalanced Partitions)	O(n²)
Average Case						O(n log n)

Why O(n log n) in Best/Average Case?
Partitioning takes O(n) (we compare each element to pivot).
Splitting happens log n times (dividing array in half each time).
Total: O(n × log n) = O(n log n).

❌ Why O(n²) in the Worst Case?
If the pivot is always smallest/largest element, one side is empty, and recursion runs n times.
Each level takes O(n), so total becomes O(n²).

Fix: Use Randomized Quick Sort (choose a random pivot).

Searching algorithms ***

1. Linear Search
Description: This is the simplest search algorithm where each element in the list is checked sequentially until the desired element is found
or the list is exhausted.
Time Complexity:
Worst Case: O(n) (n is the number of elements in the list)
Best Case: O(1) (if the element is at the start)
Space Complexity: O(1)
When to Use: Best for small or unsorted datasets. Works on any data structure (arrays, linked lists, etc.) and does not require the dataset to be sorted.

2. Binary Search
Binary Search is a Divide & Conquer algorithm used to efficiently find an element in a sorted array.
Instead of checking every element like linear search, it cuts the search space in half at each step.

When to Use:
Array (or search space) is sorted
Need faster performance than O(n)

How It Works:
Find the middle element of the array.
If it's equal to the target, return the index.
If the target is less, search the left half.
If the target is greater, search the right half.
Repeat until low > high.

Operation			Complexity
Time				O(log n)
Space (iterative)	O(1)
Space (recursive)	O(log n) (due to call stack)

Trees***
In data structures, a tree is a hierarchical structure used to represent data in a non-linear way.
It consists of nodes connected by edges, and is commonly used to model relationships like those in a family tree, organization chart, file systems, etc.

| Term        | Description                                  |
| ----------- | -------------------------------------------- |
| **Node**    | Basic unit holding a value or data.          |
| **Root**    | The topmost node of the tree (no parent).    |
| **Child**   | A node that descends from another node.      |
| **Parent**  | A node that has one or more children.        |
| **Leaf**    | A node with no children.                     |
| **Edge**    | A connection between a parent and a child.   |
| **Subtree** | Any node and its descendants.                |
| **Depth**   | Distance from the root node to a given node. |
| **Height**  | Distance from a node to its deepest leaf.    |


        A       ← root
      /   \
     B     C
    / \     \
   D   E     F     ← leaves
   
A is the root
B, C are children of A
D, E are children of B
D, E, and F are leaves
B is a subtree with nodes B, D, E

Types of Trees
Binary Tree – Each node has at most 2 children
Binary Search Tree (BST) – Binary tree with sorted structure
AVL Tree / Red-Black Tree – Self-balancing BSTs
Trie – Tree for prefix matching (used in autocomplete)
Heap – Tree used for priority queues
N-ary Tree – Node can have N children (e.g., file system)

Heap
A Heap is a special kind of binary tree used primarily to implement priority queues.It satisfies two main properties:

Complete Binary Tree
All levels are fully filled except possibly the last, which is filled from left to right.
This makes heaps easy to store in arrays.

Min-Heap: Parent ≤ children
(The smallest element is always at the root)
         1
       /   \
      3     5
     / \   / 
    4   8 6


Max-Heap: Parent ≥ children
(The largest element is always at the root)
         100
       /     \
     90       80
    /  \     /  
  70   60  50



Common Use-Cases:
Priority Queues
Dijkstra’s shortest path
Heap Sort
Top K problems (e.g., Top K frequent elements)
Median finding from a stream (using two heaps)
